# Тест-кейсы основного сценария

Владелец — участник B (QA). Прогон — на мобильном и веб-клиенте MAX перед каждым слиянием в main и каждый вечер.

## main — сценарий шаблона (заменить после выбора идеи)
| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть бота, нажать «Начать» | Приветствие и меню из двух кнопок |
| 2 | Нажать «Познакомиться» | Бот просит написать имя |
| 3 | Отправить пустое сообщение / стикер | Бот просит повторить, сценарий не ломается |
| 4 | Отправить имя | «Приятно познакомиться, <имя>!» и снова меню |
| 5 | Отправить случайный текст вне сценария | «Не понял сообщение…» и меню |
| 6 | Открыть мини-апп | Индикатор загрузки → приветствие с именем |
| 7 | Отключить интернет, открыть мини-апп | Сообщение об ошибке и кнопка «Повторить» |
