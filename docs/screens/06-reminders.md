# Экран 6. Напоминания

**Где:** бот. Сообщение приходит само по расписанию. Логика — `docs/spec/reminders.md`; здесь только тексты и кнопки.

## Что видит пользователь

```yaml
reminder:
  d30: "Через месяц, {date} — {title}. К этому сроку нужно подготовиться — предупреждаю заранее."
  d7: "Через 7 дней, {date} — {title}. Если опоздать: {penalty}"
  d1: "Завтра, {date} — {title}. Это последний день срока."
  overdue: "Срок {date} прошёл, отметки нет: {title}. Если вы уже всё сделали — отметьте, и я перестану считать его просроченным."
  snooze: "Напоминаю: {date} — {title}."
  task: "{when}, {date} — {title}."
  grouped: "{when}, {date} — {count_words}: {titles}. Откройте календарь — там подробности и отметки."
  shift_note: " (перенос с {original_date}, выходной)"
  snooze_ok: "Хорошо, напомню завтра в {hour}:00."
  btn_done: "Отметить выполненным"
  btn_howto: "Как сделать"
  btn_snooze: "Напомнить завтра"
  btn_open: "Открыть календарь"
```

- `{date}` — «28 октября»; если дата перенесена — сразу после неё `shift_note`.
- `{penalty}` — `penalty_text` из справочника, не меняется и не считается.
- `{when}` для `task` и `grouped` — «Через месяц» / «Через 7 дней» / «Завтра» / «Сегодня» / «Через N дней».
- `{count_words}` — «два срока», «три срока»; `{titles}` — названия через «и» / запятую.

| `kind` | Текст | Кнопки (ряды) |
|---|---|---|
| `d30` | `d30` | «Как сделать» «Открыть календарь» |
| `d7` | `d7` | «Отметить выполненным» / «Как сделать» «Напомнить завтра» |
| `d1` | `d1` | «Отметить выполненным» / «Как сделать» |
| `overdue` | `overdue` | «Отметить выполненным» / «Как сделать» |
| `snooze` | `snooze` | «Отметить выполненным» / «Как сделать» |
| `task` | `task` | «Отметить выполненным» / «Открыть календарь» |
| несколько на одну дату | `grouped` | «Открыть календарь» |

## Действия

| Кнопка | Что происходит | Куда |
|---|---|---|
| «Отметить выполненным» | Отметка + отмена будущих уведомлений | Экран 8 |
| «Как сделать» | — | Экран 7 |
| «Открыть календарь» | `open_app` | Экран 14 |
| «Напомнить завтра» | Создаёт `snooze`; **кнопка исчезает из исходного сообщения** (редактируем клавиатуру) | Ответ `snooze_ok` |

## Состояния

- **Событие отмечено до отправки:** уведомление не уходит (проверка перед отправкой).
- **Нажатие на кнопку по уже отмеченному событию:** экран 8, состояние «уже отмечено».
- **Сообщение не доставлено:** одна повторная попытка через час, дальше событие просто ждёт в мини-приложении.
- **Часовой пояс не выбран:** считаем московским и показываем это в профиле.

## Данные

`title`, `due_date`, `original_date`, `penalty_text`, `needs_prep`, id события для callback-кнопок, `Profile.timezone`.
Callback-данные кнопок: `r:<action>:<item_type>:<item_id>` (укладываемся в лимит длины payload MAX).

## Аналитика

- `reminder_sent` с `kind`, `item_id`, `grouped` — при отправке
- `reminder_clicked` с `kind`, `action` — при нажатии

## Не делаем

Не шлём больше лимита из `reminders.md`. Не даём отложить второй раз.

## Готово, когда

- [ ] За 30 дней приходят только события с `needs_prep: true`
- [ ] После отметки ни одно следующее уведомление по событию не приходит
- [ ] Два события на одну дату дают одно сводное сообщение
- [ ] О просроченном событии бот пишет один раз
- [ ] Время отправки совпадает с часовым поясом профиля
- [ ] После «Напомнить завтра» кнопка пропадает из сообщения
