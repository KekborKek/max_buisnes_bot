# Экран 14. Список ближайших событий — главный экран

**Где:** мини-приложение, первый экран после «Открыть календарь». Если профиля нет — вместо него экран 18.

## Что видит пользователь, сверху вниз

1. **Шапка:** слева переключатель «Список | Месяц» (D8: две кнопки, активна «Список»), справа — кнопка **«Профиль»**: иконка человека + подпись цветом акцента темы (`--text-themed`), зона нажатия 44 px. *Решение человека 29.09:* строка «ИП · УСН 6% · без сотрудников» убрана — её не узнавали как кнопку; характеристики ИП — на экране 19.
2. **Секция «Просрочено»** (`CellHeader`) — только если такие события есть.
3. **Секция «Сегодня»** — только если есть.
4. **Секция «Эта неделя»** — до ближайшего воскресенья включительно.
5. **Секция «Дальше»** — остальное на 90 дней вперёд. *Решение человека 29.09:* по умолчанию видны первые 3 строки, под ними кнопка «Показать ещё N» (N — сколько скрыто); по нажатию — весь список и кнопка «Свернуть». Если строк ≤ 3 — кнопки нет. Остальные секции не сворачиваются. Развёрнутость живёт в памяти приложения до закрытия: после карточки 16 и «Назад» секция остаётся развёрнутой.
6. **Строка события** (`CellSimple` в `CellList`): слева дата «28 окт», метка категории (`Dot`), название в одну строку с обрезкой, справа статус — галочка у выполненных, слово «Просрочено» у просроченных. Если у даты есть год (не текущий, например «5 янв 2027») — год второй строкой мелким шрифтом под датой, а не в одну строку, чтобы не наезжать на название (#105); строк без года это не касается. Строка события общая с экраном 15 (день в сетке месяца).
7. **Кнопка «+ Задача»** (`Button`), закреплена внизу экрана.

Выполненные события остаются в своей секции, но опускаются в её конец.

```ts
list: {
  profileButton: "Профиль",                                   // 29.09, временный текст техлида
  tabList: "Список",
  tabMonth: "Месяц",
  sectionOverdue: "Просрочено",
  sectionToday: "Сегодня",
  sectionWeek: "Эта неделя",
  sectionLater: "Дальше",
  showMore: (hidden: number) => `Показать ещё ${hidden}`,     // 29.09, временный текст техлида
  showLess: "Свернуть",                                       // 29.09, временный текст техлида
  statusOverdue: "Просрочено",
  addTask: "+ Задача",
  emptyTitle: "Ближайших сроков нет",
  emptyText: "Добавьте свою задачу или посмотрите месяц целиком.",
  emptyMonth: "Открыть месяц",
},
```

## Действия

| Элемент | Куда |
|---|---|
| Строка события | Экран 16 |
| «Месяц» | Экран 15; выбранный режим запоминается (`localStorage` в try/catch) |
| «+ Задача» | Экран 17, пустая форма |
| «Профиль» в шапке | Экран 19 |
| «Показать ещё N» / «Свернуть» | Разворачивает / сворачивает секцию «Дальше» без перехода |

## Состояния

- **Грузится:** шапка видна сразу (профиль из `/api/me`), на месте списка три серые строки (D6).
- **Пусто:** `emptyTitle`, `emptyText`, кнопки «+ Задача» и «Открыть месяц».
- **Ошибка:** плашка `common.error` с «Повторить»; если список уже был загружен — он остаётся.
- **Получилось:** список с ближайшим событием наверху, без прокрутки.

## Данные

`GET /api/me` → профиль. `GET /api/calendar?from=<сегодня−∞>&to=<сегодня+90>` — все просроченные без отметки, события на 90 дней вперёд и все свои задачи в этом окне. Поля строки: `due_date`, `title`, `category`, `status`. Статус считает бэкенд.

## Аналитика

`miniapp_opened` с `start_param`, `has_profile = true` (событие уже пишется бэкендом при `/api/me` — не дублировать).
`list_expanded` с `hidden` — нажата «Показать ещё N» (29.09).

## Не делаем

Поиск, фильтры по категориям, сортировку вручную, pull-to-refresh.

## Готово, когда

- [ ] Ближайшее событие видно без прокрутки на экране телефона
- [ ] Просроченные всегда выше остальных
- [ ] После отметки выполнения событие уходит в конец своей секции и получает галочку
- [ ] Переключение «Список | Месяц» не перезагружает данные заново
- [ ] Работает в мобильной и в веб-версии MAX, в светлой и тёмной теме
- [ ] Кнопка «Профиль» видна как кнопка в обеих темах, шапка не ломается на 320 px
- [ ] В «Дальше» видно 3 строки, «Показать ещё N» показывает остальные, «Свернуть» — обратно
