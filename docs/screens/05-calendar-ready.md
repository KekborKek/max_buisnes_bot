# Экран 5. Календарь готов

**Где:** бот, одно сообщение — момент первой ценности.
**Шаг:** после «Собрать календарь» на экране 3 (или «Собрать заново» на экране 1).

## Что сделать перед сообщением

1. Выбрать из справочника записи, у которых `applies_if` совпадает с профилем.
2. Рассчитать даты до 31 декабря следующего года с переносом (`data-model.md`, правила дат).
3. Создать `UserObligation` (повторная сборка не плодит дубли — уникальный ключ).
4. Создать уведомления (`reminders.md`).
5. Записать `Profile.calendar_built_at`.

## Что видит пользователь

```yaml
calendar_ready:
  body: "Готово. Добавил {count} {count_word} до конца года. Ближайшее — {next_date}: {next_title}. Напомню за 30, 7 и 1 день — в 10:00 по вашему часовому поясу. Свои задачи тоже можно вести здесь — просто напишите их мне."
  empty: "По вашему профилю обязательных сроков до конца года нет. Добавьте свою задачу — напишите мне о ней."
  no_employee_items: "События по сотрудникам пока не собираю — только ваши собственные сроки."   # D16, текст правит UX
  btn_open: "Открыть календарь"
  btn_settings: "Настройки"
```

`{count}` — число событий **до конца текущего года** (в базе хранится и следующий, D22). `{count_word}` — «событие / события / событий» по числу. Пример: «Добавил 23 события до конца года. Ближайшее — 28 октября: авансовый платёж по УСН за 9 месяцев.»

Если `has_employees = true` — строка `no_employee_items` отдельным абзацем.

Кнопки: «Открыть календарь», «Настройки». «Настройки» показывается, только когда готов экран 13.

## Действия

| Кнопка | Куда |
|---|---|
| «Открыть календарь» | `open_app` → экран 14 |
| «Настройки» | Экран 13 |

## Состояния

- **Ни одного события:** `calendar_ready.empty`, без кнопки «Настройки».
- **Сборка упала:** `common.error` + «Повторить»; профиль не теряется, повтор идемпотентен.

## Данные

Число событий, дата и название ближайшего, настройки напоминаний по умолчанию.

## Аналитика

`calendar_built` с `items_count` и `seconds_since_start` (от `Profile.started_at`).

## Не делаем

Не присылаем список всех 23 событий в чат — для этого мини-приложение.

## Готово, когда

- [ ] Число событий совпадает с тем, что видно в мини-приложении до конца года
- [ ] Ближайшее событие — действительно ближайшее к сегодняшней дате в поясе пользователя
- [ ] Кнопка открывает мини-приложение и в мобильной, и в веб-версии
- [ ] От `/start` до этого экрана — меньше двух минут
- [ ] Ни на одном шаге не запрашивался ИНН
- [ ] Повторная сборка не создаёт дублей событий и уведомлений
