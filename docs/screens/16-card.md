# Экран 16. Карточка одного события

**Где:** мини-приложение. Открывается из списка (14), из сетки (15) и из сообщений бота (через `start_param` `item_<type>_<id>`).
Кнопка «Назад» — `BackButton` MAX Bridge → туда, откуда пришли; из бота — на экран 14.

## Что видит пользователь — обязательство

| Блок | Пример | Компонент |
|---|---|---|
| Заголовок | Авансовый платёж по УСН за 9 месяцев | `Typography` |
| Дата и статус | 28 октября, среда · Предстоит · Налоги (+ `Dot`) | `Typography`, `Dot` |
| Что сделать | Те же три шага, что на экране 7, нумерованным списком | `CellList` |
| Если пропустить | Пени за каждый день просрочки, дальше — требование от налоговой | `CellSimple` |
| Основание | НК РФ, ст. 346.21 · ссылка на источник · сверено 20.09.2026 | `CellSimple` + ссылка |
| Подвал | `disclaimer.not_advice` | `Typography` мелким |

Если дата перенесена — под датой строка «перенос с 25 октября, выходной».

Кнопки: «Отметить выполненным» (основная), «Неверный срок» (второстепенная).

## Что видит пользователь — своя задача

Заголовок, «5 ноября, четверг · Предстоит · Своё», строка «Напомню за день в 10:00». Блоков «Что сделать», «Если пропустить», «Основание» нет.
Кнопки: «Отметить выполненным», «Перенести», «Удалить».

```ts
card: {
  sectionHowto: "Что сделать",
  sectionPenalty: "Если пропустить",
  sectionBasis: "Основание",
  source: "Источник",
  checked: (date: string) => `сверено ${date}`,
  shifted: (date: string) => `перенос с ${date}, выходной`,
  remindAt: (when: string, hour: number) => `Напомню ${when} в ${hour}:00`,
  markDone: "Отметить выполненным",
  undoDone: "Отменить выполнение",
  wrongDate: "Неверный срок",
  wrongDateThanks: "Спасибо, проверим",
  reschedule: "Перенести",
  delete: "Удалить",
  deleteConfirm: "Точно удалить?",
  deleted: "Задача удалена",
  overdueBanner: (date: string) => `Срок прошёл ${date}`,
  doneBanner: (date: string) => `Выполнено ${date}`,
  notFound: "Этого события больше нет",
  backToList: "К списку",
  disclaimerMark: "Вы отметили обязательство выполненным. Продукт не проверяет факт оплаты или отправки отчётности.",
  disclaimerAdvice: "Это не налоговая консультация. Суммы не считаем.",
},
```

## Действия

| Кнопка | Что происходит | Куда |
|---|---|---|
| «Отметить выполненным» | `POST .../done`; статус меняется прямо в карточке; под ним строка `disclaimerMark`; кнопка становится «Отменить выполнение»; будущие уведомления отменены | Остаёмся на экране. **Сообщение в бот не шлём** (D20) |
| «Отменить выполнение» | `DELETE .../done` | Остаёмся |
| «Неверный срок» | `POST /api/obligations/{id}/report` | Уведомление внизу `wrongDateThanks` (D7), кнопка неактивна |
| «Перенести» | — | Экран 17 с текущими значениями |
| «Удалить» | Первое нажатие — текст `deleteConfirm` на 3 с (D8); второе — `DELETE /api/tasks/{id}` | Экран 14 + уведомление `deleted` |

## Состояния

- **Грузится:** заголовок и дата видны сразу (из списка), остальное — серые плашки.
- **Просрочено:** сверху плашка `overdueBanner`.
- **Выполнено:** сверху плашка `doneBanner`, кнопка «Отменить выполнение».
- **Не найдено** (удалили в другом окне, старая ссылка из бота): `notFound` + кнопка «К списку».
- **Ошибка отметки:** общая плашка, статус прежний.

## Данные

`GET /api/items/{type}/{id}`. Если у обязательства пусто любое из полей «основание» или «дата сверки» — оно вообще не попадает в продукт (валидация справочника), карточка всегда полная.

## Аналитика

- `item_card_opened` с `item_id`, `source`
- `item_done` / `item_undone` с `source = card`
- `wrong_date_reported` с `source = card`

`howto_opened` здесь **не** шлём: шаги в карточке видны сразу, и метрика «Открыли „Как сделать“» считается только по нажатиям в боте.

## Не делаем

Редактирование обязательства, комментарии, вложения.

## Готово, когда

- [ ] Все пять блоков заполнены у каждого обязательства
- [ ] Ссылка на источник открывается из мини-приложения
- [ ] После отметки в карточке видна строка о том, что продукт не проверяет факт оплаты
- [ ] Отметка из карточки сразу видна в списке и отменяет будущие напоминания
- [ ] У обязательства нет кнопок «Перенести» и «Удалить»
- [ ] Старая ссылка на удалённую задачу даёт `notFound`, а не пустой экран
