# Экран 15. Месяц сеткой

**Где:** мини-приложение, второй режим главного экрана (переключатель «Месяц» на экране 14).
**Компонент:** своей сетки в `@maxhub/max-ui` нет — CSS-сетка 7 колонок из `Typography` и `Dot` (D5).

## Что видит пользователь

1. Та же шапка, что на экране 14, с активной «Месяц».
2. Строка навигации: `IconButton` «‹», название месяца «Октябрь 2026», `IconButton` «›», кнопка «Сегодня».
3. Строка дней недели «Пн … Вс».
4. Сетка месяца: под числом — до трёх точек (`Dot`) по категориям событий этого дня, одна точка на категорию. Сегодняшнее число обведено; выбранное — залито.
5. Под сеткой — список событий выбранного дня теми же строками, что на экране 14.

По умолчанию выбран сегодняшний день.

```ts
month: {
  today: "Сегодня",
  weekdays: ["Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс"],
  dayEmpty: "В этот день сроков нет.",
  monthEmpty: (month: string) => `В ${month} обязательных сроков нет`,   // «В ноябре…» — предложный падеж из словаря месяцев
  addTask: "+ Задача",
},
```

## Действия

| Элемент | Куда |
|---|---|
| Число | Выбирает день; список под сеткой обновляется без перехода |
| Строка события | Экран 16 |
| «‹» / «›» | Соседний месяц. **Свайпа нет** (D5) |
| «Сегодня» | Текущий месяц, выбран сегодняшний день |
| «+ Задача» | Экран 17, дата = выбранный день, если не в прошлом (иначе — завтра); после сохранения — назад сюда, выбран день новой задачи |

Листать можно на 12 месяцев назад и 12 вперёд от текущего; дальше стрелка неактивна.

## Состояния

- **Грузится:** сетка видна сразу, точки появляются после загрузки.
- **Месяц пуст:** под сеткой `monthEmpty` + кнопка «+ Задача».
- **День пуст:** под сеткой `dayEmpty`.
- **Ошибка:** общая плашка; сетка остаётся на экране.

## Данные

`GET /api/calendar?from=<1-е число>&to=<последнее число>`, сгруппировать по `due_date` на фронте. Загруженные месяцы кешируются в памяти на время сессии.
Выходные в сетке никак не выделяются — производственный календарь нужен только для расчёта дат.

## Аналитика

`month_opened` — при переключении на режим «Месяц».

## Не делаем

Свайп, неделя/год, перетаскивание событий.

## Готово, когда

- [ ] Дни с событиями отличаются от пустых и в светлой, и в тёмной теме
- [ ] Переключение месяцев работает на год вперёд и назад
- [ ] Выбранный день виден не только цветом (заливка + жирное число)
- [ ] Событие из сетки открывает ту же карточку, что из списка
- [ ] Сетка помещается в ширину 320 px без горизонтальной прокрутки
- [ ] «+ Задача» есть всегда, не только когда месяц пуст (кнопка не дублируется); после сохранения новая задача видна точкой в сетке и в списке выбранного дня без повторной загрузки
