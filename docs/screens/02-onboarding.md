# Экран 2. Четыре вопроса

**Где:** бот, четыре сообщения подряд. Следующий вопрос приходит сразу после ответа на предыдущий.
**Шаг:** профиль. После четвёртого ответа — экран 3 **без дополнительного нажатия**.

## Что видит пользователь

```yaml
onboarding:
  q1: "Вопрос 1 из 4. Какой доход был за 2025 год?"        # D2
  q1_lt10: "До 10 млн ₽"
  q1_10_20: "10–20 млн ₽"
  q1_20_60: "20–60 млн ₽"
  q1_gt60: "Больше 60 млн ₽"
  q2: "Вопрос 2 из 4. На каком вы режиме?"
  q2_usn6: "УСН 6%"
  q2_usn15: "УСН 15%"
  q2_patent: "Патент"
  q2_ausn: "АУСН"
  q3: "Вопрос 3 из 4. Есть ли у вас сотрудники?"
  q3_no: "Работаю сам"
  q3_yes: "Есть сотрудники"
  q4: "Вопрос 4 из 4. Ваш часовой пояс — московский? Напоминания буду присылать в 10:00 по нему."
  q4_msk: "Москва, UTC+3"
  q4_other: "Другой пояс"
  q4_list: "Выберите часовой пояс:"
  btn_unknown: "Не знаю"
  btn_back: "Назад"
  use_buttons: "Выберите один из вариантов ниже."
```

Раскладка кнопок (не больше двух в ряд):

| Вопрос | Ряды |
|---|---|
| 1 | `lt10` `10_20` / `20_60` `gt60` / «Не знаю» |
| 2 | `usn6` `usn15` / `patent` `ausn` / «Не знаю» «Назад» |
| 3 | «Работаю сам» «Есть сотрудники» / «Назад» |
| 4 | «Москва, UTC+3» «Другой пояс» / «Назад» |
| 4 → «Другой пояс» (D3) | Калининград (UTC+2) · Самара (UTC+4) / Екатеринбург (UTC+5) · Омск (UTC+6) / Красноярск (UTC+7) · Иркутск (UTC+8) / Якутск (UTC+9) · Владивосток (UTC+10) / Магадан (UTC+11) · Камчатка (UTC+12) / «Назад» |

Подписи поясов — в `texts.yaml` под `onboarding.tz.<iana>`; значение кнопки — IANA-идентификатор: `Europe/Kaliningrad`, `Europe/Samara`, `Asia/Yekaterinburg`, `Asia/Omsk`, `Asia/Krasnoyarsk`, `Asia/Irkutsk`, `Asia/Yakutsk`, `Asia/Vladivostok`, `Asia/Magadan`, `Asia/Kamchatka`.

## Действия

- Любой ответ → сохраняется в `Profile` → следующий вопрос.
- «Назад» → предыдущий вопрос; новый ответ перезаписывает старый.
- «Не знаю» на доходе → `income_band = unknown`; на экране 3 считаем доход ниже порога и говорим об этом.
- «Не знаю» на режиме → `regime = usn6` (самый частый) и на экране 3 предлагаем исправить в профиле.
- «Другой пояс» → сообщение `q4_list` со списком; выбор → экран 3.
- После четвёртого ответа → `Profile.nds_payer` вычисляется → экран 3.

## Состояния

- **Человек написал текст вместо нажатия:** `use_buttons` и те же кнопки текущего вопроса снова.
- **Ушёл и вернулся через час:** ответы сохранены (`DialogState`), бот продолжает с незаданного вопроса при любом следующем сообщении.
- **Нажал кнопку из старого сообщения** (например, вопрос 1, когда уже на 3): ответ принимается, бот продолжает со следующего за ним вопроса.

## Данные

`Profile.income_band`, `regime`, `has_employees`, `timezone`. Состояние шага — в существующем `DialogState`. Пятый вопрос не добавляем: каждый лишний стоит активации.

## Аналитика

- `onboarding_answer` с `step` и `value` — на каждый ответ
- `onboarding_completed` с `seconds_since_start` — после четвёртого

## Не делаем

Не спрашиваем ИНН, имя, регион, ОКВЭД. Не даём ввести доход числом.

## Готово, когда

- [ ] Все четыре вопроса проходятся кнопками, клавиатура не нужна ни разу
- [ ] «Назад» возвращает на предыдущий вопрос и меняет сохранённый ответ
- [ ] После четвёртого ответа экран 3 приходит сам
- [ ] Часовой пояс сохранён как IANA и виден в профиле
- [ ] Ни одна подпись кнопки не длиннее 20 символов
- [ ] Текст вместо кнопки не ломает сценарий
