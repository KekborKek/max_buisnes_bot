# Спецификации экранов и сообщений

Владелец — участник A (UX/UI). Одна спека = один файл `docs/screens/<имя>.md`. Спека — это готовое ТЗ для агента.

## Шаблон
```markdown
# Экран/сообщение: <название>
Где: бот | мини-апп        Сценарий: <ссылка на шаг в user flow>
## Что видит пользователь
Текст (ключ в texts.yaml / texts.ts), элементы, кнопки и их порядок.
## Действия
Кнопка «…» → что происходит → куда ведёт.
## Состояния
- загрузка:
- пусто:
- ошибка (какая и что предлагаем):
- успех:
## Данные
Что нужно от бэкенда (поля), откуда берутся.
## Событие аналитики
Какое `track(...)` отправляем.
## Готово, когда
Проверяемые пункты.
```
