# Экран 9. Своя задача текстом

**Где:** бот. Ответ на любое свободное сообщение, в котором распознана дата. Делает продукт полезным между налоговыми датами.
**Когда срабатывает:** после завершения онбординга. До него свободный текст обрабатывает экран 2 (`use_buttons`).

## Что видит пользователь

Пользователь пишет «оплатить аренду 5 ноября» и получает:

```yaml
task:
  confirm: "Задача: «{title}». Срок — {date}, напомню {remind_when} в {hour}:00. Сохранить?"
  saved: "Добавил. Всего в календаре {count} {count_word}."
  past_date: "{date} уже прошло. Сохранить на {next_year_date}?"
  duplicate: "Такая задача уже есть на {date}."
  cancelled: "Хорошо, не сохраняю."
  btn_save: "Сохранить"
  btn_edit: "Изменить"                 # D12
  btn_cancel: "Отмена"
  btn_add_anyway: "Добавить всё равно"
  btn_yes: "Да"
  btn_open: "Открыть календарь"
```

- `{title}` — текст сообщения без распознанной даты, первая буква заглавная, обрезан до 60 символов.
- `{remind_when}` — «за день» (значение по умолчанию).

Кнопки подтверждения: «Сохранить» / «Изменить» «Отмена». После сохранения — `saved` + «Открыть календарь».

## Разбор даты

Правилами, без языковой модели. Поддерживаем четыре формата:

| Формат | Пример | Результат |
|---|---|---|
| число + месяц словом | «5 ноября», «5 нояб» | ближайшее такое число, не в прошлом, иначе `past_date` |
| ДД.ММ(.ГГГГ) | «05.11», «5.11.2026» | то же |
| относительный день | «сегодня», «завтра», «послезавтра» | |
| день недели | «в понедельник», «в пн» | ближайший будущий такой день; сегодняшний не считается |

Дата не найдена → экран 10, случай «не нашёл дату». Слова без даты и без действия → экран 10, «не понял».

## Действия

| Кнопка | Что происходит | Куда |
|---|---|---|
| «Сохранить» | Создаёт `Task` и `task`-уведомление | `saved` + «Открыть календарь» |
| «Изменить» | `open_app` с параметром черновика | Экран 17 с заполненными названием и датой |
| «Отмена» | Ничего не сохраняет | `cancelled` |
| «Да» (на `past_date`) | Дата → тот же день следующего года | снова `confirm` |
| «Добавить всё равно» | Создаёт дубль | `saved` |

## Состояния

- **Дата в прошлом:** `past_date` + «Да» «Отмена».
- **Задача с таким же названием и датой уже есть:** `duplicate` + «Добавить всё равно» «Отмена».
- **Сохранение не прошло:** `common.error` + «Повторить»; текст задачи не теряется (черновик в `DialogState`).

## Данные

`Task.title`, `due_date`, `remind_offset_days = 1`, `remind_hour = 10`. Категория всегда `custom`. Напоминание — одно (D11).

## Аналитика

`task_created` с `source = chat`, `remind_offset = 1`.

## Не делаем

Не распознаём время («в 15:00») и повторы («каждый месяц»). Не используем LLM.

## Готово, когда

- [ ] Все четыре формата даты из таблицы разбираются; на каждый есть юнит-тест
- [ ] Задача появляется в списке и в сетке месяца с меткой «Своё»
- [ ] Напоминание по задаче приходит в срок
- [ ] Нераспознанная дата не теряет текст задачи
- [ ] «Изменить» открывает форму с уже заполненными полями
