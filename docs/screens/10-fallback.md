# Экран 10. Бот не понял или сервис не работает

**Где:** бот. Три разных ответа. Главное правило: **из любого есть выход одним нажатием.**

## Что видит пользователь

```yaml
fallback:
  unknown: "Я понимаю сроки и задачи. Напишите, например: «оплатить аренду 5 ноября»."
  no_date: "Понял задачу «{title}», но не увидел дату. Когда напомнить?"
  service: "Не получилось. Проверьте интернет и нажмите «Повторить». Ваши данные на месте."
  unknown_3: "Если нужного нет в календаре, напишите нам."
  service_2: "Сервис временно недоступен. Напоминания придут в срок, календарь не потерян."
  btn_open: "Открыть календарь"
  btn_about: "О сервисе"
  btn_tomorrow: "Завтра"
  btn_week: "Через неделю"
  btn_pick: "Выбрать дату"
  btn_retry: "Повторить"
  btn_write: "Написать нам"
```

| Случай | Когда | Текст | Кнопки |
|---|---|---|---|
| Не понял | Нет ни даты, ни похожего на задачу текста | `unknown` | «Открыть календарь» «О сервисе» |
| Не нашёл дату | Похоже на задачу (есть глагол / от 2 слов), даты нет | `no_date` | «Завтра» «Через неделю» / «Выбрать дату» |
| Сервис не ответил | Исключение при обработке | `service` | «Повторить» |

## Действия

| Кнопка | Куда |
|---|---|
| «Завтра», «Через неделю» | Экран 9 с подставленной датой. Payload `fb:tomorrow:<id>` / `fb:week:<id>` — id своего черновика; из старого сообщения — `task.draft_stale`, ничего не предлагает (#96) |
| «Выбрать дату» | `open_app` (`start_param = task_draft_<id>`) → экран 17 с названием; из старого сообщения — пустая форма и тост (#96) |
| «Повторить» | Повтор последнего действия пользователя |
| «Открыть календарь» | Экран 14 |
| «О сервисе» | Экран 11 |
| «Написать нам» | Ссылка `SUPPORT_URL` (D13) |

## Состояния

- **Три непонятых сообщения подряд:** к `unknown` добавляется `unknown_3` и кнопка «Написать нам» (если `SUPPORT_URL` задан).
- **Два сбоя подряд:** вместо `service` — `service_2`.
- Счётчики — в `DialogState`, сбрасываются любым успешным действием.

## Данные

Последнее действие пользователя для «Повторить» (`DialogState`). Существующий `handlers/fallback.py` переписывается под эти тексты; старые ключи `errors.*` удаляются, когда на них не останется ссылок.

## Аналитика

- `fallback_shown` с `case`
- `date_not_parsed` — на случай «не нашёл дату»

## Не делаем

Не отвечаем на вопросы про налоги в свободной форме.

## Готово, когда

- [ ] Ни в одном тексте нет кода ошибки и слова «сервер»
- [ ] Каждый из трёх случаев воспроизводится на демо одним действием
- [ ] После «Повторить» человек продолжает с того же места
- [ ] Без `SUPPORT_URL` кнопка «Написать нам» не появляется
